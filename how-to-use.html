STEP 0

大会プリセット・大会名の設定（任意）

登録済みの大会プリセットを選択し、大会ナンバリング（半角数字）を入力すると、以下の項目がすべて自動でセットされます。

  • 大会名（例：`Vic-Seekers #1`）
  • start.ggのBracket URL（選択したナンバリングから自動取得）
  • 大会ロゴ画像（用紙右下に自動配置）
  • 基本最大セット数・ラウンド途中変更設定
  • その他追加オプション（大会進行上の注意事項テキストなど）

※プリセットにない大会でも、「大会名（任意）」欄に自由に入力するか、start.gg API取得時に大会名を自動取得できます。

STEP 1

参加者データの取得（シードCSV または start.gg API）

1プールあたり 6名〜40名 のトーナメントに対応しています（5名以下または41名以上のプールが含まれる場合はエラーが表示されます）。データの読み込み方法は以下の2通りから選べます。

方法A：start.gg APIから取得（推奨）

自動設定対応

APIトークンとBracket URLを入力してボタンを押すだけで、全プールの参加者データ・トーナメント形式・通過人数・進出先フェーズ名・配信台・事前DQまで一括で自動取得します。

🔑 start.gg API token の取得手順（初回のみ）

  1. start.gg左下のアイコンから 「Developer Settings」 を開く
  2. 「Create new token」 を押し、任意の名前を入力して保存
  3. 発行されたトークンをコピーし、Bracket Printerに入力（次回以降はブラウザに自動保存されます）

方法B：シードCSVのアップロード

オフライン対応

start.ggの管理画面（Seeding画面のExport CSV）から出力したシードCSVファイルをそのままアップロードできます。

📄 自動参照されるCSVの列

・A列 (Phase)：フェーズ名 / C列 (Pool)：プール名

・E列 (Pool Seed)：プール内シード順位

・M列 (Player GamerTag)：右側のCheck-in名簿に使用（Prefix付き）

・N列 (Player Short GamerTag)：ブラケット枠内に使用（Prefixなし）

STEP 2

初期設定（手順2 〜 手順6）とブラケット描画

2. トーナメント形式の選択

ダブルエリミネーション または シングルエリミネーション（ともに6〜40名対応）を選択します。

3. フェーズ通過人数の指定

勝者側（0 / 1 / 2 / 4人）・敗者側（0 / 1 / 2 / 4 / 8人）から選択します。
※Grand Final（シングルはFinal）まで完結させる場合は「0人」を選択してください。

4 & 5. 最大セット数（Bo）の指定・途中変更

Bo5 / Bo3 / カスタム奇数から選択できます。また、「変更する」を選ぶと指定したラウンド以降（例：Winners Semi-Final 以降）の最大セット数を個別に切り替えられます。

6. 通過先フェーズ名の入力

予選通過枠の下部に印字される次フェーズ名（例：`Top 48` / `Aクラストーナメント`）を入力します（Grand Final完結時は入力不要です）。

すべての項目を設定すると ブラケットを描画する ボタンが有効化されます！

STEP 3

プレビュー上の対戦カードをクリックして個別設定（事前DQ / 配信台）

ブラケット描画後、プレビュー画面上の任意の対戦カード（ブロック）をクリックすると、個別設定ウィンドウが開きます。

🚫 事前確定DQの記入と自動連動

  • DQになったプレイヤーのスコア欄に自動で 「DQ」、対戦相手のスコア欄に 「✔」 を記入します。
  • 不戦勝となったプレイヤーは次のラウンドの該当スロットへ自動で名前が繰り上がります。
  • 勝者側でDQになったプレイヤーは、敗者側の該当スロットへ自動で落下し、敗者側でも自動的に「DQ」となります。

📺 配信台ラベルの設定

  • 「配信台に設定する」にチェックを入れ、配信チャンネル名を入力すると、モノクロ印刷でも見やすい角丸破線枠と配信ラベルが付与されます。
  • CSV読み込み時・API取得時のどちらでも手動で追加・編集が可能です。

STEP 4

ロゴの追加・高機能テキストボックス

🖼️ 右下にロゴを追加

白黒（モノクロ・グレースケール）のPNG画像をアップロードすると、トーナメント用紙の右下に配置されます。縦160pxを超える画像は自動で縮小されるため、比率を気にせずそのまま読み込めます。

📝 高機能テキストボックス

大会進行上の注意事項やタイムスケジュールなどを自由な位置に配置できます。太字(B)・斜体(I)・下線(U)・1px単位のフォントサイズ変更・左/中央/右寄せに対応しており、複数のテキストボックスが重なった場合はクリックするだけで前面と後面を入れ替えられます。

STEP 5

画像(.jpg)保存・PDFファイルの直接ダウンロード

画面左下の3つの出力ボタンから、用途に合わせて保存できます。PDF出力時はブラウザの印刷画面を開かず、直接 `.pdf` ファイルとしてダウンロードされます。

画像として保存(.jpg)

現在表示しているプールを高解像度のJPG画像としてダウンロードします。SNS共有や確認用に最適です。

現在のプールをPDF出力

現在プレビュー中の1プールのみを、指定した用紙サイズ・向きのPDFファイルとして直接ダウンロードします。

全プールをPDF一括出力

読み込んだ全プール（Pool A1, A2...）を1つの複数ページPDFにまとめて直接ダウンロードします。
